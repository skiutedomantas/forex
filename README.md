
# Forex Currency Exchange 💱

An interactive currency converter that allows users to convert between different currencies using exchange-rate data retrieved from an API.

## Overview
Built with a focus on simplicity and usability, this project combines a clean interface with real-time currency data to make currency conversion quick and intuitive.

## Features
- Convert between multiple currencies
- Fetch currency exchange rates from an API
- Interactive currency selection and amount input
- Responsive design for desktop and mobile
- Dynamic conversion results

## Built With
- React
- Tailwind CSS
- Currency Exchange API
